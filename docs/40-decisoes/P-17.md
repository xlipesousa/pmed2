# P-17 — `estado_glosa` e `localizacao_atual` não têm restrição no banco

Descoberto ao conferir o código contra a [[Sobre a especificação original|especificação original]].

## O problema

A migration original declarou as colunas como `enum`. A migration
`2025_04_16_214627_aumentar_tamanho_colunas_pacotes` converteu todas para `string(50)`,
**removendo a restrição** — e os valores que o código grava nunca foram reconciliados com
os que o enum declarava.

### `estado_glosa`

| Enum declarado (5) | Código grava (9) |
|---|---|
| `Não identificada` | `Não identificada` |
| `Glosa identificada` | `Glosa Identificada` ← caixa diferente |
| `Recurso pendente` | *(nunca usado)* |
| `Recurso deferido` | `Recurso Deferido` ← caixa diferente |
| `Recurso indeferido` | `Recurso Indeferido` ← caixa diferente |
| — | `Existência de Glosa Notificada` |
| — | `Ofício de Glosa Retirado` |
| — | `Aguardando Recurso de Glosa` |
| — | `Recurso recebido` |
| — | `Recurso não recebido` |

### `localizacao_atual`

Enum declarado com capitalização (`Protocolo`, `Lisura`, …, `Arquivados` no plural); o
código compara em minúsculas (`protocolo`, `lisura`, `arquivado` no singular).

## Por que é grave

**Um typo em `$pacote->estado_glosa = '...'` não falha** — grava a string errada e o pacote
sai silenciosamente da máquina de estados. Como toda a lógica de fluxo compara strings
exatas ([[Estados do pacote]]), um pacote nesse limbo simplesmente para de responder às
ações, sem erro em log nenhum.

O risco é maior porque as comparações estão espalhadas por ~5.900 linhas de controller,
sem constante central.

## Correção proposta

Não é reintroduzir o enum — a lista real mudou e vai mudar de novo. É:

1. Criar um **enum PHP** (`App\Enums\EstadoGlosa`, `App\Enums\Localizacao`) com os valores
   reais, e usar `cast` no model `Pacote`. Isso faz o Laravel rejeitar valor inválido na
   escrita, sem depender do banco.
2. Substituir as comparações de string espalhadas pelo enum.
3. Rodar um `SELECT DISTINCT estado_glosa, localizacao_atual FROM pacotes` em produção
   **antes**, para descobrir se já existe dado fora da lista — se existir, decidir a
   migração de dados antes de travar a validação.

Depende da rede de testes ([[Dívida técnica]], item 1) existir antes, porque toca o caminho
crítico de todas as transições.
