# P-3 — Sem TLS em homologação nem em produção

Os dois ambientes servem HTTP puro, sem certbot instalado em nenhum dos dois. Produção é
acessada por IP (`10.122.8.15`) e por um DNS interno (`pmed2.4rm.eb.mil.br`) sem
certificado.

[[ADR-02]] já deixou o nginx do host como ponto único de proxy — é o lugar certo para
instalar TLS/certbot quando esta pendência for endereçada.
