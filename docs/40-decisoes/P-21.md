# P-21 — Base de produção contém recursos cadastrados como pacotes

Consequência do [[Bug do protocolo]]. O caminho que gerava o problema já foi bloqueado em
`PacotesController::store()`, mas **os registros criados antes continuam na base de
produção**.

## Impacto

| Onde | Efeito |
|---|---|
| Pacotes glosados | Travados em `Aguardando Recurso de Glosa` indefinidamente — o registro do recurso foi para outro lugar |
| Relatórios e gráficos | Contagem de pacotes inflada; totais financeiros distorcidos |
| Fluxo | Os "pacotes" falsos não completam o ciclo, porque não são faturas reais |

Nenhum dos três dá erro. O sistema opera normalmente com a base distorcida — é por isso que
o problema sobreviveu tanto tempo.

## Estado

**Em investigação.** A extensão real é desconhecida: a base de desenvolvimento não reflete a
de produção, então é preciso restaurar um backup de produção em ambiente controlado antes de
medir.

Plano de investigação e correção:
[`specs/001-caca-bug-protocolo/`](../../specs/001-caca-bug-protocolo/spec.md).

## Chave de detecção

Duplicidade de `numero_fatura` para a mesma `ocs_psa_id` entre pacotes não anulados — uma
fatura é única por par `(pacote, OCS/PSA)`. Consultas em [[Bug do protocolo]].
