# P-8 — `.env` ainda está no histórico do Git

> [!danger] Marcada CRÍTICA e nunca executada
> `git filter-repo` para limpar `.env` do histórico do Git foi planejado em
> `planos/plano-retomada.md` e **nunca executado**. O repositório é público. Qualquer
> segredo que já tenha estado em algum `.env` commitado no passado permanece recuperável
> por qualquer pessoa com acesso ao histórico completo.

**Ação necessária:** identificar todos os segredos que já passaram por `.env` versionado
(rotacioná-los, presumindo comprometimento), depois `git filter-repo` para remover o
arquivo do histórico, seguido de force-push coordenado e comunicado a todos com clone
local.

Esta é a pendência de maior risco do inventário. Ver [[Dívida técnica]] (item F5.3 do
plano de normalização).
